Translate `malignancy.region.label` to the matching atlas zone:
- "Right frontal" → **Right frontal lobe**
- "Left frontal" → **Left frontal lobe**
- "Anterior midline" → **Anterior midline (frontal parasagittal / falcine)**
- "Right temporal/parietal" → **Right temporal–parietal region**
- "Left temporal/parietal" → **Left temporal–parietal region**

- "Left occipital" → **Left occipital lobe**

### OUTPUT FORMAT — produce EXACTLY these five markdown headings, in this order.

## TECHNIQUE
One short sentence describing the input modality and preprocessing. Use: "T1-weighted contrast-enhanced MRI, single axial slice. Preprocessing: CLAHE + ImageNet normalization, 224×224 inference."

## FINDINGS
2–4 sentences. State the suspected lesion using the type from `prediction.class`. State the location using the ATLAS ZONE MAPPING and the side. State `size_pct` and `size_category`. Describe margins / mass effect only in qualitative terms (do NOT invent enhancement patterns not present in the input). If `consistency` is "atypical", add: "Location is atypical for this prior — recommend review." If `uncertainty.needs_review` or `ood.is_ood` is true, add one sentence noting the model is less confident on this specific case.

## IMPRESSION
1–2 sentences. State the most likely classification (using `prediction.class` and the atlas-zone name), confidence percent, `best_model`, malignancy `score`/10, and `base_risk` tier. Frame as "Findings compatible with …".

## DIFFERENTIAL
A short numbered list (1–3 items) of plausible alternative diagnoses based ONLY on the predicted class:
- Glioma → astrocytoma WHO grade II–III; oligodendroglioma; metastasis (if solitary).
- Meningioma → WHO grade I meningioma; schwannoma (extra-axial); dural metastasis.
- Pituitary → pituitary adenoma; craniopharyngioma; Rathke cleft cyst.
- No Tumor → omit this section entirely (do not output the heading).

## RECOMMENDATION
2–3 sentences. Request a full-protocol contrast MRI (T1, T2, FLAIR, T1 post-gadolinium) for confirmation. Suggest specialist referral (neurology for low/low-medium risk, neurosurgery for high risk or mass effect). Add urgency derived from `base_risk`: "Urgency: routine (2–4 weeks)" for LOW, "soon (1–2 weeks)" for LOW-MEDIUM, "expedited (within days)" for HIGH. If `focus_crop.is_consistent` is false, add: "Note: model attention may not have been on the lesion — confirm visually."
